# Definition of Done

## Foundation (this execution)

- Desktop project and Git repository exist.
- Monorepo boundaries, strict TypeScript, environment contract, lint/format/test/build scripts, Prisma migration location, Docker dependencies, and CI foundation exist.
- All requested documents clearly mark current, planned, and future functionality.
- Clean install plus format check, lint, typecheck, tests, Prisma validation, and build pass.
- No secrets, fabricated product behavior, or unapproved V1 features are included.

## Feature increment

A feature is done only when acceptance criteria and threat considerations are documented; contracts and migrations are versioned; tenant isolation and permissions are enforced; validation and safe errors exist; important actions are audited/observable; unit/integration/security/failure tests pass; UI states are honest and accessible; operational docs are updated; and no placeholder action suggests unsupported behavior.

## V1

V1 is done only when a real beta business reliably completes enquiry → understanding → structured lead → qualification → reviewed draft → authorized email → follow-ups → reply detection/cancellation → complete history → real analytics, including recovery from defined failures. Security gates, staging deployment, backups/restores, monitoring, runbooks, beta evidence, and stakeholder acceptance are required.
